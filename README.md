# Python Expense Tracker

A command-line expense tracking application built with Python.

The application allows users to record, manage, search, and analyze their personal expenses. Data is stored locally in a JSON file.

## Features

- Add new expenses
- Edit and manage expense data
- Delete expenses
- Search expenses by title or category
- Filter expenses by category
- Calculate total expenses
- Calculate average expenses
- Find the highest expense
- Display category summaries
- Generate monthly reports
- Custom expense dates
- Input validation
- Persistent data storage with JSON

## Technologies

- Python 3
- JSON
- File I/O
- datetime
- Functions
- Lists and dictionaries
- Exception handling
